## 🚀 Key Features

* **🩺 Doctor Shift Mode & Zero-Overwhelm Reassurance**: Reassures customers that automated booking is active while Dr. Joie is on hospital rounds/surgery.
* **⚖️ Northern Delicacies Kilishi (Strictly Weighed by Kg)**: 0.25kg, 0.5kg, 1.0kg, 2.0kg, and 5.0kg tiers with cut & spice customizer.
* **📦 Authentic Northern Delicacies Line**: Weighed Kilishi, Donkwa snack balls, and Yaji Suya pepper blend.
* **🚫 Real-Time "Ordered Finish / Sold Out" Engine**: 1-click doctor toggle prevents taking unfulfillable orders.
* **🕒 Urgency-Based Delivery Scheduler**:
  * ⚡ **Urgent Flash Dispatch (60-90 Mins)**
  * 🕒 **Scheduled Windows (Morning, Afternoon, Evening)**
  * 🎂 **Advance Pre-Order (Cakes & Events)**
* **⚠️ Slot Capacity Protection**: Prevents kitchen overwhelm by capping maximum orders per delivery window.
* **🛵 Trusted Ondo Bikemen Fleet**: Rider Kola, Rider Tayo, Rider Emmanuel with live ETA countdown in minutes and transit radar.
* **💳 Multi-Channel Paystack Checkout**: Debit Cards, Instant Bank Transfer (virtual account), and USSD codes.
* **📲 Direct WhatsApp Order Dispatch**: Generates complete structured invoices directly to `09064839054`.
* **🤖 24/7 Virtual Concierge**: Automated AI assistant answering questions about availability, pricing, and routes.
* **✨ Conglomerate Event Styling**: Inquiry flow for dessert tables, tiered wedding cakes, and corporate boxes.

## 📦 Local Development

```bash
# 1. Clone repository
git clone <your-repo-url>
cd joie-cakes-and-more

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```

## 🌐 Deploy to Vercel

### Method 1: Git Repository (Recommended)
1. Push this repository to GitHub, GitLab, or Bitbucket:
   ```bash
   git remote add origin https://github.com/<your-username>/joie-cakes-and-more.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the repository.
4. Framework Preset will auto-detect as **Vite**.
5. Click **Deploy**!

### Method 2: Vercel CLI
```bash
npx vercel
```
